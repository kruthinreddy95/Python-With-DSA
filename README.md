# Python with DSA (Data Structures & Algorithms)

A comprehensive collection of Python programs covering basics, data structures, and algorithms.

## 📁 Folder Structure

### 1️⃣ **01_basics/** - Fundamental Concepts
- `01_sum.py` - Calculate sum of array
- `02_reverse.py` - Reverse an array
- `03_calculator.py` - Basic arithmetic calculator
- `04_electricity_units.py` - Conditional logic practice
- `05_strings_count.py` - String operations

### 2️⃣ **02_arrays_and_strings/** - Arrays & Data Structures
- `01_array_even_numbers.py` - Filter even numbers
- `02_remove_duplicates.py` - Remove duplicate elements
- `03_largest_repeating_number.py` - Find second largest element
- `04_hashing_dict.py` - Dictionary operations
- `05_two_pointer_technique.py` - Two pointer approach
- `06_min_length_subarray.py` - Cumulative sum

### 3️⃣ **03_searching/** - Search Algorithms
- `01_linear_search.py` - Linear search basic
- `02_linear_search_optimized.py` - Linear search optimized
- `03_binary_search.py` - Binary search

### 4️⃣ **04_sorting/** - Sorting Algorithms
- `01_bubble_sort.py` - Bubble sort (O(n²))
- `02_selection_sort.py` - Selection sort (O(n²))
- `03_insertion_sort.py` - Insertion sort (O(n²))
- `04_merge_sort.py` - Merge sort (O(n log n))

### 5️⃣ **05_patterns/** - Pattern Printing
- `01_number_pattern_1_12_123.py` - Number pattern
- `02_reverse_right_angle_triangle.py` - Reverse triangle pattern

### 6️⃣ **06_advanced/** - Advanced Concepts
- `01_recursion_factorial.py` - Factorial using recursion
- `02_fibonacci.py` - Fibonacci sequence
- `03_function_example.py` - Function concepts

---

## 🚀 How to Use

### Run a Single File
```bash
python3 01_basics/01_sum.py
```

### Run All Files in a Folder
```bash
for file in 03_searching/*.py; do python3 "$file"; done
```
